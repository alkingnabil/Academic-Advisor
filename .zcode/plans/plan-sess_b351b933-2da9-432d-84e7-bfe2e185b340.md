## What we're building

A Telegram bot acting as **المرشد الأكاديمي المساعد** (Academic Advisor Teaching Assistant) for the Faculty of Computers & Information, Qena University:

- **Group (-1003657081670):** responds **only when addressed** — @mention, reply to one of its messages, or /command — and always replies tagging the student by name (@username or first name).
- **Private chat:** responds to anyone who messages it.
- **Memory:** remembers what was said in the group (rolling history per chat + auto-extracted facts like exam dates, registration deadlines, announcements). Private chats keep isolated per-user memory — never leaks into group context (matches the committee PDF's confidentiality rule).
- **Language:** Egyptian Arabic (ar-EG), technical terms in English.
- **Brain:** OpenAI-compatible client → dahl provider / glm5.3flash (URL + key in `.env`).
- **Knowledge base:** committee PDF (already extracted), الائحة 2019 docx, the course-map site (prerequisite graph + GPA rules for CS/IS/IT/AI), WhatsApp chat exports for tone/FAQ calibration.
- **Runs 24/7 on Render:** long polling + tiny keep-alive HTTP server on `PORT`, deploy-ready from day one. Runs locally with `node .` too.

**M3 — Brain:** llm.js client + persona.js (loads knowledge/), memory.js (rolling 50-message window per chat, background fact extraction after each reply, /reset clears personal history), graceful error handling (no swallowed errors — tell the user in Arabic if the LLM call fails). *Gate: real end-to-end test in the group + private chat.*

**M4 — Verify & ship:** live tests (group mention → tagged answer; private chat; memory recall of a fact told earlier in group), clean-code-guard pass on the full diff, README (run + Render deploy steps), final commit.
